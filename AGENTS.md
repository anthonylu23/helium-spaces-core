# Agent guidelines for helium-spaces-core

This is anthonylu23's fork of imputnet/helium, used as the `helium-chromium`
submodule of [helium-spaces](https://github.com/anthonylu23/helium-spaces).
Read that repo's `AGENTS.md` and `docs/spaces/` first.

- Feature work does not happen here. Our patches live in the helium-spaces repo
  under `patches/spaces/`. Edit this repo only to pin Helium or to hotfix a
  Helium patch that breaks our build, and log the reason in
  `docs/spaces/rebase-log.md` of the parent repo.
- Never push to, open PRs against, or file issues on imputnet/helium or any
  other imputnet repository. Helium's maintainers do not accept AI-assisted
  contributions, and nothing from this fork goes upstream.
- Do not commit without the human's approval.
